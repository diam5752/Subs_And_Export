# Code of conduct

gsubs welcomes focused, respectful contributions and reports that improve the
product for its users.

## Expected behavior

- Be clear, constructive and respectful, including when disagreeing.
- Focus feedback on observable behavior, code and user impact.
- Respect privacy. Use redacted mock data and the appropriate private reporting
  channel for sensitive matters.
- Give others credit for their work and correct mistakes openly.

## Unacceptable behavior

- Harassment, threats, discrimination or targeted personal attacks.
- Publishing another person's private information without explicit permission.
- Posting customer media, transcripts, credentials, cookies, payment data or other
  personal information in public repository content.
- Deliberately disrupting discussions, tests, releases or project infrastructure.

## Scope and enforcement

This policy applies to repository issues, pull requests, reviews, discussions and
other project spaces. Maintainers may edit or remove content and restrict
participation when conduct is unsafe or persistently disruptive.

Report a serious or privacy-sensitive incident confidentially through the
[private reporting form](https://github.com/diam5752/Subs_And_Export/security/advisories/new).
Start the report title with `Conduct report` and share only the minimum information
needed to assess it. The maintainer will review the report privately, hear the
relevant parties where appropriate and respond proportionately.
